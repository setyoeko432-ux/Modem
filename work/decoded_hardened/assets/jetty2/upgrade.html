Firmware Upgrade

Upload and apply modem system firmware updates

Upgrade Instructions
  1. Download the verified firmware image file for this modem model.
  2. Click Choose File and select the firmware package.
  3. Click Upload to transfer the file to the device.
  4. Click Upgrade to flash the firmware. Process takes ~3-4 minutes and reboots automatically.
